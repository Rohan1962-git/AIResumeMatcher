# AI Resume & Job Matching Platform

A web application built with Python and Django that helps users analyze their resumes against job descriptions and track job applications.

## Features

- Resume upload in PDF and DOCX formats
- Resume and job description matching
- Match score and matched skills
- Missing skills suggestions
- ATS-friendly resume checks
- Resume analysis history
- Dashboard with application statistics and charts
- Job application tracker
- Downloadable analysis reports
- User registration and login

## Technologies Used

- Python
- Django
- HTML5
- CSS3
- JavaScript
- Bootstrap
- SQLite
- PostgreSQL
- Chart.js

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Rohan1962-git/AIResumeMatcher.git
cd AIResumeMatcher
```

### 2. Create and activate a virtual environment

**Windows:**

```bash
python -m venv venv
venv\Scripts\activate
```

### 3. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Apply database migrations

```bash
python manage.py migrate
```

### 5. Start the development server

```bash
python manage.py runserver
```

Open http://127.0.0.1:8000/ in your browser.

## Project Purpose

This project was developed to practice Django web development, resume processing, job matching, database management, authentication, and application tracking.
